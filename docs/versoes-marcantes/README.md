# Versões marcantes

**Português** · [English](README.en.md) · [Voltar à documentação](../README.md)

Este acervo guarda cópias jogáveis de versões que marcaram o desenvolvimento de Maré Miúda. As entregas ficam congeladas para consulta e reprodução, mesmo quando o jogo atual mudar.

| Data | Edição | Por que guardar |
| --- | --- | --- |
| 26/11/2026 | [Primeira Partida](primeira-partida-2026-11-26/README.md) | A abertura ficou mais leve e os primeiros passos, a virada da maré e a recuperação do Siri ficaram mais fáceis de entender. |

Para acrescentar outro marco: crie uma pasta datada, guarde o arquivo original ou os insumos para reconstruí-lo byte a byte e registre seu SHA-256, descreva o que mudou e como jogar e adicione o link ao acordeão da raiz. Não substitua arquivos históricos por montagens novas.

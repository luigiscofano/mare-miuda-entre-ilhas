# Animação · estudo visual de alagamento

[Voltar ao guia de arte](../README.md) · [Abrir ou baixar o vídeo MP4](Mare-Miuda-Alagamento-81-Configuracoes.mp4)

Este estudo de direção visual testa a leitura da lâmina d’água em pixel art. Os exemplos mostram a maré subindo e descendo sobre os baixios, inclusive a água passando à frente do siri. É uma referência visual aprovada para documentação, não uma gravação do jogo ou uma mecânica já implementada.

## O que aparece no vídeo

| Tempo | Exemplo |
| --- | --- |
| 0:00 | Entrada da água por quatro bordas. |
| 0:03,5 | Entrada da água por uma única fonte. |
| 0:07 | Interior molhado. |
| 0:10,5 | Bolsão fechado. |
| 0:14 | Cobertura parcial do siri. |
| 0:17,5 | As 81 configurações de vizinhança, organizadas em nove painéis. |

Os exemplos isolam as configurações locais para comparar o contorno e o sentido do movimento da água. A animação do vídeo não define regras, tempos nem comportamento do jogo.

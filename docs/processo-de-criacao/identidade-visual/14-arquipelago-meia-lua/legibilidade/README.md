# Meia-Lua · navegação mais clara

Preserva o cenário sem casas e a espuma branca. Dá respiro aos cais, diferencia o primeiro trecho dourado de ligações futuras em verde-água e distingue o acesso de cada ilha com um losango. Nem todos os mundos representados estão implementados. Trata-se de uma prévia, não de uma captura.

Em `fontes/` está a camada editável de navegação. Rode `python exportar.py` (Pillow) para reproduzir em 288 × 216 e 3×, sem suavização. O exportador verifica que as diferenças se restringem à camada de navegação e que a espuma fica intacta.

# Cabo Baixo · placas mais claras

Cenário, trilhas e siri original da Placa de Areia permanecem intactos. Os quatro números agora têm contraste consistente e a estrela identifica o desvio opcional sem depender da cor. A primeira placa ganhou uma pequena folga em relação à pinça do siri. Prévia, não captura nem mudança no jogo.

A camada editável está em `fontes/`. Rode `python exportar.py` (Pillow) para reproduzir o PNG nativo em 192 × 144 e a ampliação inteira de 4×. O exportador verifica que todo o restante, inclusive o siri, permanece igual pixel a pixel.

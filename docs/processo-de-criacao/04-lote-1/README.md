# 04 · Primeiro lote de regiões: Recifes e Mangue

Versão de teste, não lançamento. A Praia abre o arquipélago caminhável; Recifes e Mangue entram em qualquer ordem, por mapas locais com três travessias em cada região. O atalho é possível ao concluir a última travessia; as duas regiões liberam apenas o sinal da Enseada, não um novo mundo jogável. A Placa de Areia e o bem-te-vi na Praia continuam preservados.

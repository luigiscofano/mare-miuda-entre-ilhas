# 06 · Praia das Conchas em duas telas

Cabo Baixo conserva as três travessias, a Ilhota opcional e o encontro da Ponta da garça. Depois do encontro, siga à direita para a Enseadinha. O embarque antigo continua disponível no mesmo ponto para não bloquear saves anteriores. Na Enseadinha, a entrada à esquerda retorna ao Cabo; o outro lado embarca depois das três travessias principais, sem exigir opcionais.

| Fase nova | Rota | Validação no motor |
| --- | --- | --- |
| Fio de areia | Principal | RRRDUDURR |
| Poças em espelho | Principal | RRDUDULLUDUDLLDUDURRU |
| Da praia ao mirante | Principal | RRDUDRR |
| Bolso da maré | Opcional | RDRRRLLLU |
| Trilha das pedras | Opcional | RURRRLRDR |
| Fragmentos do areal | Opcional | UUDRDRRRRUDUDLLUU |

R/L/U/D significam direita, esquerda, cima e baixo. As seis soluções são reproduzidas pelo mesmo motor da interface. São dez fases regulares e um encontro existente. Os dois chefes planejados não são contados como prontos.
